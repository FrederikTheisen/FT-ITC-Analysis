# Scientific claim and evidence matrix

This record defines the scientific validation scope for audit A06. The new
references are deterministic synthetic calculations derived outside the
production models. They complement the [published benchmarks](../PublishedBenchmarks/README.md);
they are not additional experimental measurements or demonstrations of
superior accuracy over other software.

The [external-software integrated-heat study](ExternalIntegratedHeats/RESULTS.md)
adds pytc-generated inputs and tests FT-ITC's prediction and parameter recovery
without baseline processing or reintegration. The raw-thermogram workflow below
remains a separate processing test. Starting with integrated heats removes
processing differences, but external injection/dilution conventions still need
explicit comparison.

All concentrations below are mol/L, volumes are L, integrated heats are J,
and molar enthalpies/offsets are J/mol unless stated otherwise. `Ka` is an
association constant in M^-1; fitting stores `log10(Ka)`, and the displayed
`Kd = 1/Ka` is in M. Each reference uses the fit to its original observations
as the central estimate. No bootstrap mean supplies a reference target.

## Settings and acceptance

The component READMEs specify equations, concentrations, dilution, exclusions,
locks, starts, weights and numerical tolerances. The following is the common
acceptance contract:

| Reference | Expected central parameters | Predetermined acceptance |
| --- | --- | --- |
| pytc Ca–EDTA | N 0.973948; Ka 4.05476e7 M^-1; ΔH −11566.9 cal/mol | 2% relative for each; 4.184 J/cal. N, Ka, ΔH and offset are free; first two injections excluded |
| Analytic raw one-site | N 1.1; logKa 6.2; ΔH −32000; offset 350 | Absolute heat error ≤2e-10 J; N/ΔH 0.2%; Ka 1%; offset 5 J/mol |
| Full two-site | N (0.65, 1.55); logKa (7.35, 5.15); ΔH (−25000, 13000); offset 1800 | N absolute 0.002; logKa absolute 0.003; ΔH relative 0.003; offset 2 J/mol; equivalent swapped labels accepted |
| Full competitive | N 1.15; logKa 7.0; ΔH −18000; offset 1800 | Same full-fit tolerances as two-site; competitor inputs held fixed |
| Sequential | logKa (6.4, 5.7, 5.0, 4.3); step ΔH (−30000, 20000, −18000, 14000), truncated for fewer steps | Forward heat 2e-12 J; fitted logKa 0.01 absolute and each ΔH 1% relative; only offset fixed |
| Dissociation | Ka 31250 M^-1; ΔH −18000; offset 1250 | Forward heat 2e-12 relative; all recovered parameters 2e-7 relative; weak/strong reference 1e-10 relative |
| Derived analyses | Temperature ΔH(25 °C) −9000, ΔCp +100; protonation intercept 1000 and slope 0.3; ionic Kd0 2e-6 and sensitivity −1.25 | Independent constants and unit checks use explicit decimal/absolute tolerances in the tests. These are exact regression targets, not empirical uncertainty coverage |

Forward tolerances allow binary64 arithmetic and, for raw files, float-valued
power/concentration import. Recovery tolerances are larger because correlated
parameters and optimizer stopping affect recovered coordinates. They were
specified before fitting and were not increased to accommodate failures.
Reference qualification tightens numerical stopping where documented. Uniform
positive SDs in some noiseless references scale the objective without changing
its least-squares optimum; they are not measured noise or evidence of interval
calibration. The displayed unweighted RMSD remains distinct from that objective.

For the published multistart reference, starts `(N, logKa, ΔH cal/mol,
offset cal/mol)` are `(0.7, 6.5, −8000, −100)`, `(1.3, 8.5, −16000, 100)`
and `(1.0, 7.0, −12000, 0)`. Both solvers use at most 20,000 iterations/
evaluations, unweighted fitting and no uncertainty estimation. The source
data and reference parameters retain their original provenance record.

## Scientific review findings

The reference work exposed and corrected six focused issues:

1. Instrument decimal-point rows and injection protocols depended on the UI
   locale. Danish settings could interpret decimal points as grouping marks;
   French settings could reject the same data. Fixed-format imports now use
   invariant floating-point parsing. English, Danish and French tests use
   the same absolute-power targets.
2. Automatic mean spline control points used the window midpoint even when
   the selected samples had a different mean time. This biased a linear
   drifting baseline. Mean power is now assigned to the mean sample time;
   saved/locked control points retain their existing behavior.
3. The monomer quadratic subtracted nearly equal numbers at weak association.
   The rationalized positive root preserves small nonzero concentrations.
4. The electrostatic plot divided natural logarithms by rounded `2.303`.
   It now uses `ln(10)` for an exact base conversion.
5. TAPSO's neutral acid charge and local pKa temperature slope were corrected;
   imidazole's heat-capacity slope was converted to the field's J/(mol K)
   units. TAPSO's existing −16 J/(mol K) heat capacity was confirmed visually
   and retained. See the source review for the limited temperature range.
6. Protonation fitted a straight line through an iterative nonlinear search,
   which could exhaust its iteration limit at realistic J/mol magnitudes.
   Direct linear least squares now evaluates the same model without that
   scaling-dependent failure. A non-finite/degenerate fit is rejected while
   preserving the previous valid result.

These changes concern scientific evaluation and processing, not the native
file format. Existing saved results are not a substitute for rerunning an
analysis affected by a corrected calculation. Review/recalculate affected
processing or derived analyses before comparing a publication candidate with
results from an older version.

## Reproduction and provenance

Run from the repository root after the normal .NET restore:

```sh
python3 AnalysisITC.Tests/ScientificValidation/RawPipeline/generate_reference.py
python3 AnalysisITC.Tests/ScientificValidation/Sequential/generate_reference.py
dotnet test AnalysisITC.Core.Tests/AnalysisITC.Core.Tests.csproj --configuration Release --no-restore
```

The two generators use only Python's standard library and never call the
application. The raw JSON records the input SHA-256. Dissociation CSVs are
human-readable copies of the frozen test arrays; the binding tests contain
their independent conservation/bisection reference calculations. All new
synthetic data and generators are original repository material under the
repository MIT license. Primary-source numerical constants are attributed;
external papers and raw third-party datasets are not copied into this folder.

See [VERIFICATION.md](VERIFICATION.md) for the tested revision, working-tree
scope, test counts and limitations. This record resolves the repository
claim/evidence gap in A06 only when those checks pass. It does not close A04
(clean builds/CI), A07 (run provenance and interval coverage), A08 (complete
distribution/data permissions), or A10 (independent reviewer tutorial and
paper bundle). An ITC practitioner's external review remains part of A10.
