# Dissociation scientific validation reference

These references validate the exposed monomer–dimer dilution model. They are
independently calculated physical cases, rather than heats generated by the
production implementation. `reference-case.csv` is an explicit-state kernel
case; `microcal-reference.csv` and `exponential-reference.csv` use the actual
concentration traces produced by `RawDataReader.ProcessInjectionsUsingMethod`.
The CSV files contain the frozen expected values used for review alongside the
executable tests in
`AnalysisITC.Core.Tests/DissociationScientificReferenceTests.cs`.

The assumed equilibrium is

```text
2 M <-> D
Ka = [D] / [M]^2
C = [M] + 2[D]
```

For each injection, the syringe contains total monomer-equivalent
concentration `Cs`, the cell volume is `V`, and the injection volume is `v`.
For the explicit-state kernel case, the cell concentration after the injection
is `C_after = Cs * cumulative_v / V`. For the imported cases, the independent
concentration formulas are `r=(1-u/2)/(1+u/2)`, `C_after=Cs*u/(1+u/2)` for
MicroCal and `r=exp(-u)`, `C_after=Cs*(1-r)` for Exponential, where
`u=cumulative_v/V`. The dimer amounts before and after mixing are independently
calculated as

```text
n_pre  = v * D(Cs) + (V - v) * D(C_before)
n_post = V * D(C_after)
q = dH_assoc * (n_post - n_pre) + offset * (Cs * v)
```

The frozen parameters are `V = 1.4e-3 L`, `Cs = 1.2e-3 M`, `Ka = 31250
M^-1` (`Kd = 32e-6 M`), `dH_assoc = -18000 J/mol dimer`, and `offset = 1250
J/mol injectant`. The first 0.25 µL injection is excluded as a priming
injection; the remaining eleven 2.5 µL injections are included in recovery.

The executable validation uses `LevenbergMarquardt` and `NelderMead`, starts
from log10(Ka) = 5.2, dH = -12000 J/mol, and offset = 0, leaves all three
parameters unlocked, uses no bootstrap iterations, and uses a uniform positive
SD of `1e-10 J` with `UseErrorWeightedFitting = true`. Uniform SD weighting
rescales every residual equally and therefore preserves the unweighted
least-squares optimum while putting the residuals on a useful numerical
scale. These SDs are not measured noise or uncertainty-calibration evidence. The test collection restores
preference defaults, then sets `OptimizerTolerance = 1.0`, standard parameter
limits, and explicit `MaxOptimizerIterations = 20000`. Predetermined
tolerances are 2e-12 relative for forward heats, 2e-14 relative for independent
mass balance, and 2e-7 relative for recovered parameters. The tight forward
tolerance is appropriate for deterministic double precision; the looser
recovery tolerance allows optimizer termination and parameter correlation.
These tests validate
the stated equilibrium, signs, units, explicit-state and imported dilution
conventions, limiting cases, and recovery for identifiable synthetic
references. They do not validate
kinetic equilibration, higher oligomers, activity coefficients, baseline
selection, concentration uncertainty, or real-data model adequacy.

Nelder–Mead uses `SolverToleranceModifier = 1e-6`; LM uses modifier 1.
These stricter numerical settings preserve the original starts and 2e-7
parameter tolerances. At ordinary interactive stopping settings, a very small
heat residual can still accompany correlated parameter errors larger than this
reference tolerance.

The weak-association boundary test uses `Ka = 1e-6 M^-1` and a strict 1e-10
relative tolerance against the cancellation-safe quadratic solution. It
failed with the former subtractive root and passes after using
`M = 2C/(1+sqrt(1+8KaC))`. The strong-association companion uses
`Ka = 1e14 M^-1`. No acceptance tolerance was loosened for this correction.

## Equation and model provenance

The MicroCal PEAQ analysis manual describes dimer dissociation as dilution of a
protein solution into buffer, assumes only monomer and dimer states, defines an
equivalent monomer concentration as `[M] + 2[D]`, and fits the dissociation
constant and dissociation enthalpy from sequential injection heats:

<https://www.malvernpanalytical.com/en/learn/knowledge-center/user-manuals/manual-microcal-peaq-itc-analysis-software-man576-01-en-00>

The original dilution-calorimetry derivation gives the same monomer–dimer
balance and the injection heat as the difference between dimer amounts in the
syringe/cell mixture before and after the injection:

<https://www.chem.gla.ac.uk/staff/alanc/itcdil.pdf>

Published experimental work also reports that injecting concentrated dimeric
protein into buffer produces endothermic dissociation heats that decrease as
cell concentration increases, consistent with the sign and trend in this
reference case:

<https://pmc.ncbi.nlm.nih.gov/articles/PMC6159223/>

Regenerate the rational MicroCal numerical fixture with
`python3 generate_microcal_reference.py` (55-digit Decimal arithmetic, no FT-ITC
calls). These local analytical checks and solver-recovery tests are not
independent external forward-model validation.
