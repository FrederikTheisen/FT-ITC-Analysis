## About \appname
\appname processes, fits, designs, and presents isothermal titration calorimetry (ITC) experiments on macOS, Windows, and Linux. All workflows are available through the graphical interface.

# Main workflow

Load data, inspect the experiment details, and define baselines and integration regions for raw thermograms. Fit an appropriate model, review the result and uncertainty, then export tables, figures, or a report.

You can also fit multiple experiments together, explore temperature, salt, or buffer dependence, and use the Experiment Designer to test a titration layout before collecting data.

## Getting started
Use **File > Open...** or drag compatible files into the window. At launch, **\enter** opens the file browser and **\space** loads the most recently used files. Inspect loaded experiments in **Overview**.

# Experiment details

Check cell and syringe concentrations, temperature, and conditions before processing or fitting. In experiment details, use **Details**, **Identifiers**, and **Attributes** to edit metadata, then choose **Apply**. External experiment and sample/batch IDs are optional descriptive labels; they do not affect fitting.

Buffer pH entry requires a finite number from 0 to 14, inclusive.

Dates recorded in data files are read-only. If only a filesystem date is available, enter a user-provided date when needed. Tandem provenance is listed under **Tandem merge origin**.

# Compatible file formats

**Raw data:** MicroCal-style `.itc`, TA Instruments `.nitc` and `.ta`, and PEAQ-ITC `.apj`.

**Origin projects:** `.opj`. The first compatible ITC worksheet supplies a raw trace when available, otherwise integrated heats. Origin fits and processing are not imported; ResultsLog text is retained as provenance.

**Integrated heats:** `.dat`, `.aff`, and `.dh`. The first injection is excluded from fitting by default; include it manually if appropriate. For `.dat` and `.aff`, choose whether to **Recalculate concentrations and ratios** from injection volumes or retain the table progression. The **Recalculate concentrations on integrated-heat import** preference sets the initial choice; you can override it for each import. Enter the experiment temperature in °C during import. `.dh` concentrations are always calculated.

For concatenated `.itc` runs, choose the MicroCal concentration progression or supply between-segment back-mixing settings when prompted.

# Saving and organizing a project

Save as `.ftxtc` to retain processing, fits, and project contents for another session or computer. Raw input files are not modified.

When opening a project with already-loaded objects, **Skip Duplicates** keeps those objects and imports new content. **Import Copies** creates separate copies with their relationships preserved.

Save after processing or fitting finishes; save commands are unavailable while busy, and autosave waits. If the project remains marked as changed after saving, save again to include the newer edits.

Drag a non-button area of a Data or Analysis Result row to reorder the list. Projects retain that order.

# Removing results and processing

**Delete All Results** removes saved Analysis Results while keeping experiment processing and attached fits.

**Clear Processing > Selected / Active / All** restores processing defaults and clears calculated baselines, integrated thermogram heats, and attached fits. Imported integrated heats, raw data, concentrations, injection choices, and attributes are retained. Saved Analysis Results remain but may be out of date. Clear Processing has no Undo and is unavailable while busy.

## Processing data
For raw thermograms, open **Processing** to define the baseline and integration regions. Integrated-heat imports skip this step. Zoom in to inspect the baseline and peak boundaries; double-click an injection to focus on it.

# Choosing a baseline

**Spline:** use when you need manual control. Move, add, remove, or lock handle points. Choose linear or smooth interpolation, point density, and mean or median local values for automatic placement.

**Polynomial:** use for a single baseline across the thermogram. The degree ranges from 0 to 24, with 12 as the default. Higher degrees allow more curvature but increase overfitting risk.

**Segmented:** use when drift differs across the thermogram. Local constant, linear, or quadratic segments are blended across peak regions.

Polynomial and segmented baselines can be converted to splines for manual adjustment. Conversion locks processing; unlock individual points to edit them while retaining the converted spline. Changing spline settings, integration regions, or fitting peaks regenerates points from the data.

# Setting integration regions

Include the peak response while avoiding unnecessary baseline noise. **Start** and **Length** are both offsets from injection onset: Start = 2 s and Length = 20 s define an 18 s region. **\peakfit** estimates end points automatically.

Drag the blue markers to adjust individual injections. When focused on one injection, **\space** copies its end-point offset to the next and advances the view. Enable **Copy start time to next** to copy both boundaries.

# Locking processing

Lock the processor to freeze processing and disable graphical edits. Lock individual spline points instead when only selected handles should stay fixed.

# How processing affects heats

An integrated heat is the area between the measured trace and its baseline within the integration region. By default, baseline fitting excludes these regions, so changing a boundary can change both the fitted baseline and the heat.

Peak fitting repeatedly estimates end points from the baseline-corrected response, recalculating the baseline between passes when it excludes integration regions. If no stable result is found, the previous regions are restored.

## Injection heat uncertainty
Injection error bars show processing-derived heat standard deviations (SDs). They combine local noise accumulated during integration with uncertainty in the baseline level. Check the baseline and integration region when an error bar is unexpectedly large; a longer region often accumulates more noise.

**Weight by injection error** uses these SDs as relative fitting weights. They are separate from parameter uncertainty, concentration uncertainty, and the displayed unweighted RMSD. A missing or zero bar does not establish that a heat is exact; integrated-heat imports have no thermogram from which to estimate this noise.

# Calculation and assumptions

The total heat SD, \sigma{q,i}, combines integration and baseline contributions:

$$
\sigma{q,i} = √( \sigma{q,i,int}^2^ + \sigma{q,i,bl}^2^ )
$$

Integration noise contributes:

$$
\sigma{q,i,int} = \sigma{p,i} · ∆*t* · √*N*{int,eff}
$$

Here, \sigma{p,i} is the local RMS power noise, ∆*t* the sampling interval, and *N*{int,eff} the effective integrated-sample count. Baseline-level uncertainty contributes:

$$
\sigma{q,i,bl} = \sigma{p,i} · (*T*{int} / √*N*{bl,eff})
$$

Here, *T*{int} is integration duration in seconds and *N*{bl,eff} the effective baseline-sample count. Effective counts account for correlation between neighboring samples using a chosen AR(1) approximation, in which correlation decays geometrically with separation. Local noise is estimated from samples before integration and near the end of the injection interval; the latter can overlap integration.

Correlation uses consecutive baseline sample pairs separated by at most twice the sampling interval, with the same eligible pairs in its numerator and normalization. Longer gaps are excluded.

These estimates do not quantify baseline-model or boundary choice, calibration error, or other systematic uncertainty. They do not validate the processing or provide confidence intervals for the true heat.

## Injection bookkeeping
Injection bookkeeping calculates cell concentrations and accounts for binding heat carried out by displaced solution. It affects the fitted curve and parameters, while measured heats and baseline integration stay unchanged.

**Discrete displacement:** the default starting point for ordinary pulse injections. Solution is displaced before appreciable mixing, then the remaining cell contents mix with the injected solution.

**Ideal continuous mixing:** assumes mixing throughout the injection. Consider it for slow injections or to compare the opposite mixing limit.

**MicroCal:** uses the documented MicroCal concentration and displaced-heat approximations. Choose it when reproducing or comparing MicroCal analyses.

These are different physical approximations; no method is assumed to be empirically superior. Injection bookkeeping is separate from dilution-heat background models and between-reload back-mixing.

# Changing the method

**Preferences > Processing > Injection bookkeeping** sets the default for new data. For an existing ordinary experiment, change the method in **Experiment Details**. This recalculates concentrations and invalidates its fits without reintegrating measured heats. Rebuild tandem experiments through the tandem tool to change their method.

Changing the preference or editing a name/comment does not switch existing data. Saved projects retain their processing until explicitly changed. If the selector shows **Saved processing — unchanged**, choose a method before recalculating concentrations.

# Discrete displacement

Let *v* be injection volume and *V* active cell volume. Each injection retains a fraction 1 − *v*/*V* of the previous cell mixture. The predicted injection heat is:

$$
*q* = *Q*{end} − (1 − *v*/*V*) · *Q*{start}
$$

Here, *Q* is equilibrium cell binding heat content. The displaced-heat correction uses the heat content before injection. Across injections with the same syringe solution, multiply the retained fractions to obtain *r*. The resulting macromolecule concentration *M* and ligand concentration *L* are:

$$
*M* = *r M*{0}
*L* = *r L*{0} + *C*{s}(1 − *r*)
$$

Here, *M*{0} and *L*{0} are concentrations at the start of that sequence and *C*{s} is syringe concentration. Each injection must be smaller than the cell volume; the total injected volume can exceed it. This follows Freire, Schön and Velazquez-Campoy (2009).

# MicroCal

Let *u* be cumulative injected volume divided by active cell volume. Every delivered injection counts, including injections excluded from fitting. The reference curves are:

$$
A{M}(*u*) = (1 − *u*/2)/(1 + *u*/2)
B{M}(*u*) = *u*(1 − *u*/2)
$$

The retained macromolecule concentration is its initial concentration multiplied by A. Starting with no ligand in the cell, ligand concentration is syringe concentration multiplied by B. These are approximate concentration curves from the *MicroCal ITC Analysis Software Using Origin User Manual* (2015), section 12.3.1, equations 2 and 4.

# Ideal continuous mixing

Using the same definitions of *u*, A and B, the concentration curves are:

$$
A{E}(*u*) = exp(−*u*)
B{E}(*u*) = 1 − exp(−*u*)
$$

The heat calculation accounts for displaced solution along the mixing trajectory. It uses a finite-injection approximation inspired by Dumas (2022), doi:10.1007/s00249-021-01588-4. It does not model imperfect mixing or kinetic single-injection experiments. Very large injections or sharp transitions need additional scrutiny because the heat calculation uses a fixed integration rule.

# Concentration updates after reloads

For MicroCal and Ideal continuous mixing, an injection from *u*{0} to *u*{1} advances the concentrations before injection, M{0} and L{0}, to M{1} and L{1}:

$$
*r* = A(*u*{1})/A(*u*{0})
M{1} = *r* M{0}
L{1} = *r* L{0} + C{s}[B(*u*{1}) − *r* B(*u*{0})]
$$

After back-mixing, use the mixed active-cell concentrations without resetting cumulative *u*. Without back-mixing, these updates reproduce the ordinary reference curves. The MicroCal update from mixed concentrations is an \appname extension derived from those curves. For tandem experiments it requires *u* < 2, beyond which the retained-fraction approximation cannot be advanced physically. Ideal continuous mixing has no finite cumulative-volume boundary.

## Model fitting
In **Analyze Data**, select a model, review parameter starting values and options, choose included injections, and run **\btnfit**. Fits use the selected experiment, or all Active experiments in **\multexp** mode. Enable **Create analysis result** to save a result for later review and export.

# Choosing a model

**One-set-of-sites:** one class of binding sites.

**Two-sets-of-sites:** two independent classes of sites.

**Sequential Binding Sites:** two, three, or four ordered binding steps, each with its own affinity and enthalpy.

**Competitive binding:** a target ligand titrated into a macromolecule already equilibrated with a competitor.

**Dissociation:** dimers in the syringe partly dissociate after injection into a cell initially containing buffer. Its heat and residual plots use post-injection total titrant concentration in µM.

# Competitor properties

For Competitive Binding, enter the competitor properties or enable **From attributes**. To obtain competitor affinity and enthalpy from a saved fit, add a **Competitor properties** attribute and select a one-set-of-sites Analysis Result. Values and uncertainties are evaluated at the experiment temperature when temperature dependence is available.

Every included experiment needs the requested attributes. A fit captures the values it uses; later attribute changes take effect only at the next fit or **Update Result**. Removing the source does not erase properties already captured by a result.

# Multiple experiments and global fitting

Mark the experiments **Active**, enable **\multexp**, and choose which parameters to share. With no shared constraints, experiments are fitted independently. Shared parameters connect them in a global fit. Temperature, salt, or buffer variation can support further analyses; see **Derived analyses**.

# Fit completion

Check whether fitting reached a limit and whether uncertainty estimation completed. The status bar reports the current stage and final outcome. A completed fit with incomplete uncertainty still needs review before its intervals are used.

# Parameter constraints and interpretation

Global parameters minimize the combined mismatch across experiments; they are not averages of separate fits. Affinity constraints can be **Independent**, **Shared ΔG**, **Shared Kd**, or **Thermodynamically linked**, where Gibbs energy follows the selected enthalpy relationship.

Affinity is fitted as log₁₀K, so a negative coordinate still represents a positive association constant. **Expanded** extends the Standard affinity range by a factor of 20 at each end; **No limits** extends it by a factor of 2000. Globally constrained affinities must remain positive and finite, but can exceed local bounds.

When comparing programs, check the model, concentration and stoichiometry definitions, injection bookkeeping, and dilution-heat treatment. Matching one convention does not make parameter values interchangeable.

## Syringe correction
Enable syringe correction when the main concentration uncertainty concerns material in the syringe rather than the cell. The result reports the fitted correction factor as α. Check this setting when comparing fitted stoichiometry between analyses.

# Scientific interpretation

An ordinary fitted N-value can absorb error in cell concentration or activity, so it is not necessarily a pure stoichiometric estimate. Syringe correction instead applies the fitted factor to the delivered titrant concentration during fitting. It changes the mass balance without changing measured heats or thermogram integration. Values fitted with and without this mode are not directly interchangeable.

## Analysis results
Open a saved **Analysis Result** to review fitted parameters, residuals, uncertainty, model settings, and warnings. **Details** lists the saved metrics and settings, editable name and comments, and reasons a result may be out of date. **Experiments** lists its members and their solution status.

Use **Update Result** after changing inputs. Existing results retain the values used by their saved fits, including captured competitor properties, until updated. Fits remain attached to Experiment Data even when **Create analysis result** is off.

# Evaluating and exporting values

Choose an evaluation temperature to inspect thermodynamic quantities. The default is the current **Reference temperature** when the measured temperature span exceeds the configured minimum, including independently fitted series; otherwise it is the mean experiment target temperature. Evaluation does not refit the data.

Use **Export result...** to choose results, summary or individual rows, value and uncertainty columns, and CSV or TSV output. The same table can be copied. Numeric tables use decimal points regardless of regional settings.

Distinguish **Combined SD** and **Approximate propagated interval** in local summaries from model-estimated SDs and CI95 intervals. See **Parameter uncertainty** for the refitting methods and **Binding assessment** for model comparisons and output restrictions.

## Result validity

Validity compares saved fit inputs with the current experiments, including temperature, concentrations, included injections and heats. Check the reasons and use **Update Result** after changing inputs. An independent collection without temperature dependence can be **Partially invalid** when only some members change. A result with shared parameters or temperature dependence becomes **Invalid** when any member's fit inputs change, even when the experiments were fitted individually.

# Fit metrics

RMSD describes unweighted heat differences even when the fitting objective was weighted. A saved global fit may also provide Molar RMSD. Compare AIC or AICc only for the same observations under the same weighting and likelihood assumptions.

# Summary uncertainty

For local parameters, **Combined SD** is the square root of between-experiment sample variance plus mean individual variance; a temperature trend uses residual variance. It describes combined spread, not the standard error of the mean, and observed spread may already include fitting noise.

The **Approximate propagated interval** describes the average or evaluated trend. It combines observed spread with separately propagated lower and upper individual interval widths, preserving possible asymmetry. Two distinct-temperature observations propagate individual errors without estimating residual spread; additional observations contribute residual spread. ΔCp uses slope uncertainty.

These intervals lack established 95% coverage, especially for small collections, and omit between-experiment covariance even when local parameters are coupled through a global fit. Shared and temperature-constrained parameters retain model-estimated uncertainty. Central values remain the fits to the original data.

## Binding assessment
Check the automatic assessment alongside the curve, residuals, and uncertainty. It compares the binding fit with a **Null model**, which describes heat without binding. **No binding detected** means this experiment does not establish binding relative to that model; it does not show that the molecules cannot bind.

Use **Modify Assessment** on a saved result to override the conclusion or restore automatic assessment. Manual assessments take precedence. **Null prediction** overlays the saved Null fit; on native macOS, choose **Analysis > Show Null Prediction** in the Analysis toolbar menu.

# Uncertainty and updates

Fits assessed **No binding detected** skip parameter uncertainty and show **Not estimated (no binding detected)**. For independent experiments this applies member by member. If you change such an assessment to **Binding detected**, use **Update Result** to estimate uncertainty; the result remains out of date until then.

Reopening evaluates saved comparison evidence with the current automatic rule while retaining manual overrides and fitted values.

# Reports, figures, and tables

**Standard reports:** list every member, but suppress no-binding estimates, RMSD, parameter tables, and fit warnings. Unavailable values appear as **—**. Inconclusive results retain binding output with a health warning. Manual conclusions are marked **(manual)**.

**Figures:** Standard report and Supporting Figure plots use the Null prediction for no-binding members and omit their c-values and correlations. Thermodynamic summary graphs omit those members in both Standard and Diagnostic reports. Final Figure has a separate **Plotted model** choice.

**Tables:** Standard exports omit binding values and RMSD for no-binding members and retain Inconclusive values. Choose **Diagnostic report** or **Diagnostic export** to inspect available attempted binding detail. **Not assessed** imposes no restriction and is not positive evidence of binding.

# Independent experiments

Each independent fit has its own Null comparison. **Member assessments** shows a common conclusion or **Mixed assessments**; this summary is not a joint statistical verdict.

If any member is effectively **No binding detected**, combined binding values and dependent analyses are omitted rather than recalculated from a subset. A pooled comparison appears only as a diagnostic in report appendices and Diagnostic Summary export columns; it uses a pooled residual-variance convention and does not determine member assessments.

# Scientific details

**AIC / AICc** compare fit quality while accounting for fitted parameter count; smaller values are preferred. Weighted criteria treat processing-derived injection errors as relative uncertainties and estimate a common variance multiplier. AICc can be unavailable with too few observations. Neither score establishes model adequacy.

The implemented Null model, **Offset**, predicts:

$$
*q*{i} = *b m*{i}
$$

Here, *m*{i} is the injected amount and *b* the constant background heat per mole of injectant. The comparison uses:

$$
ΔAICc = AICc(null) − AICc(binding)
$$

Positive values favor binding. The chosen screening cutoffs are **No binding detected** at ΔAICc ≤ 0, **Inconclusive** at 0 < ΔAICc < 15, and **Binding detected** at ΔAICc ≥ 15. They are not a significance test and have no calibrated false-positive guarantee.

## Parameter uncertainty
Choose residual bootstrap, leave-one-out refitting, or profile likelihood in the analysis settings. Bootstrap estimates variation under resampled residual noise; leave-one-out checks sensitivity to omitted data; profile likelihood searches for a 95% interval while allowing other parameters to refit.

The reported parameter value always comes from the best fit to the original data. Refitting estimates uncertainty without replacing it with a resampling mean or median.

The uncertainty style preference selects SDs, intervals, or both when available; it does not change the fit. **Bootstraps** shows the requested count, its tooltip shows retained refits, and reports count complete retained replicates. Use **Update Result** to rerun uncertainty, then check the completion message and counts. Independent members can retain individual uncertainty without a complete combined set.

# Residual bootstrap

Included best-fit residuals are sampled with replacement and added to best-fit predictions to create synthetic datasets for refitting. An unweighted fit centers and samples residuals in heat units. A weighted fit divides by each injection SD before centering and sampling, then multiplies each draw by the target injection's SD. Resampling assumes comparable residual spread after any weighting. Weighted fitting requires positive, finite SDs for all included injections.

To compensate for noise absorbed by fitting, centered residuals are multiplied by √(*n* / (*n* − *p*)), where *n* is included-observation count and *p* fitted-parameter count. Shared global fits use pooled counts; independent members use their own. In either case, *n* must exceed *p*.

The reported SD is the root-mean-square deviation of retained refit values from the original best fit. The 95% limits are their 2.5th and 97.5th percentiles. Derived quantities can use transformation or propagation rather than direct percentiles; see **Derived analyses**.

# Leave-one-out refitting

Each refit omits one injection for a single-experiment fit, or one entire experiment for a global fit. Concentrations, uncertain model options, and parameter locks stay at their primary-fit settings. This measures sensitivity to omission under those fixed inputs.

# Profile likelihood

Each fitted parameter is held at trial values while the remaining free parameters are refitted. The 95% threshold uses an F-calibrated worsening of the residual score. Weighted profiles keep injection SDs as relative weights and estimate overall residual scale separately, without changing the stored SDs.

Shared global profiles use the complete fitting objective; independently fitted members are profiled separately.

A bound reached before the threshold leaves that endpoint unavailable; the bound is not a confidence limit. A displayed profile SD is an equivalent scale derived from the two endpoints, not Gaussian sampling uncertainty. Profiles do not create a bootstrap ensemble or joint covariance model. Save as `.ftxtc` to retain intervals and censoring information.

After **Update Result**, check whether the completion message says the previous profile result was retained rather than replaced.

# Concentration uncertainty

Enable concentration uncertainty to vary cell and syringe concentrations in residual-bootstrap refits using their entered SDs. Concentrations with no SD stay fixed. Leave-one-out and profile likelihood keep all concentrations fixed.

The fractional SD, CV, determines a positive lognormal multiplier with mean 1 and SD CV. Its log-space parameters are:

$$
σ²{log} = ln(1 + CV²)
μ{log} = −σ²{log}/2
$$

## Parameter correlations
Open **Correlation** to inspect how fitted coordinates vary together across complete residual-bootstrap refits. For independent experiments, select the member to inspect. Point to a cell for Pearson's *r* and its approximate 95% Monte Carlo precision interval; check the panel's refit counts and warnings before interpreting it.

The view requires at least 30 complete refits and two varying coordinates. Fixed parameters are omitted unless **Unlock parameters** let them vary during bootstrap. Affinity coordinates are log₁₀K{a}, rather than displayed K{d}; a shared Gibbs-energy coordinate is labeled separately.

Red indicates negative correlation, blue positive, and white zero. Stronger colors indicate larger squared magnitude, while cell values show *r* itself. An interval spanning zero means the sign is unresolved at the current simulation precision.

# Calculation and limits

Only refits with finite values for every displayed coordinate enter the matrix. For *B* complete refits, off-diagonal intervals use Fisher's transformation:

$$
*z* = atanh(*r*)
*z* ± 1.959964/√(*B*−3)
$$

The endpoints are transformed back with tanh. Diagonal self-correlations have no interval.

This describes finite-simulation precision of the correlation, not uncertainty in either parameter or evidence of identifiability, causality, or model validity. Failed refits can make the retained ensemble selective; the interval does not account for that. With *B* complete rows, covariance rank is at most *B*−1. That structural sample-count limit is separate from numerical rank and scientific adequacy.

## Derived analyses
For one-set-of-sites results, open the additional analysis tabs when the experiments provide the required variation and metadata:

**Temperature:** inspect temperature dependence and run Spolar–Record structuring analysis when the temperature span is sufficient.

**Ionic strength:** requires salt metadata for every experiment and three ionic-strength conditions with usable affinities. Select conditions in increasing order, each more than half the **Minimum ionic-strength span (mM)** above the previous selected condition. Counter-ion analysis requires three distinct positive ion activities with usable affinities. Repeated observations remain part of each fit.

Saved ionic-strength plots retain the buffer-inclusion setting used for their fit. A new calculation uses the setting captured when the result was opened or updated.

**Protonation:** requires available buffer ionization enthalpy at every member's experimental temperature and at least two distinct enthalpy values. **Available analyses** identifies buffers and experiments with unavailable thermochemistry. These buffers remain selectable for ordinary fitting. Missing thermochemistry disables protonation analysis for the whole collection.

Check buffer constants and conditions before interpreting these analyses. Completed structuring outputs retain their saved estimates and evaluation temperature until rerun.

# Scientific assumptions

Spolar–Record structuring analysis is evaluated at the isoentropic point, where model-estimated binding entropy is zero (ΔS = 0). Structuring, salt, and protonation outputs are conditional model estimates.

Buffer constants depend on reaction, temperature, and solution conditions; registry values can be approximate or unknown. **Include buffer in ionic-strength calculation** uses the transition nearest the recorded pH, treats it as two species, and assumes monovalent acid/base counterions. Salt and other buffer contributions are added separately. Numerical convergence does not establish chemical accuracy, especially at high concentration.

The TAPSO pKa temperature correction is a local approximation for 20–30 °C; do not assume it is equally reliable outside that range.

# Uncertainty in derived values

Displayed limits for \dg, \tds, and other derived quantities can use transformation or propagation rather than percentiles of fully recalculated refits. Profiles do not directly search intervals for quantities depending on several fitted parameters. Central values remain the fit to the original data.

For linked temperature relationships, profile intervals propagate reference Gibbs energy and enthalpy coordinates approximately, omitting their correlations. Bootstrap and leave-one-out evaluate complete refitted relationships. Spolar–Record Monte Carlo samples its linked inputs independently, so its uncertainty also omits their correlations.

# Interpreting report values

Fitted values and fit settings come from the saved result. Processing details, observations, and injection tables describe **Current experiment data**. Fit and Residual use the reported solution, with residual = observed − predicted. Supporting experiments show observations only. Recheck result validity after editing processing.

Each result experiment's processing or data-availability details identify its saved injection-bookkeeping method. Mixed methods within a result are flagged in its overview and report warnings. The result summary identifies saved buffer subtraction. **Baseline method** describes the current baseline type and its details; imported integrated heats have no baseline or integration record.

Conditions show nominal initial concentrations in syringe ▸ cell order, target temperature, and recorded buffer and salt conditions. **Combined parameters** states its evaluation temperature: the current reference-temperature preference when the temperature span exceeds the configured minimum, otherwise the mean target temperature. This is independent of the result-view temperature and does not refit data.

Fixed estimates have no uncertainty interval. Combined spread and approximate propagated intervals remain distinct from model-estimated uncertainty; see **Analysis results**. Exported warnings remain visible, and structurally unusable results cannot be exported.

**Binding** remains selectable after **No binding detected**. **Null** plots the saved dilution-heat prediction against buffer-corrected observations; offset correction and confidence bands are unavailable. **None** shows processed observations without model curves, residuals, fitted parameters, or model-based corrections.

Set energy units, axes, typography, and curve settings before export. **Auto Y axis includes excluded points** lets excluded injections affect automatic heat and residual ranges; explicit limits take precedence. **Active** and **All** figure exports use a subfolder named after the project, or the local export date for an unsaved session. **Export Associated Final Figures** uses a subfolder named after the result. Choose a parent folder for either export.

Figure batches ask once before replacing existing PDFs; **Cancel** stops the entire export without writing files. Repeated exports reuse the same filenames. Numeric suffixes distinguish experiment names that collide within a batch.

# Exporting and checking plots

Use **File > Export**, context menus, or the result exporter for data and figures. The selected tool determines whether traces, heats, uncertainties, or fitted parameters are included. Fitted values can also be copied from the result view.

Figures use current processing. After changing baselines or integration regions, rerun the fit before exporting; processing edits do not automatically refit curves. Supporting Figure retains its sources and layout during the current document session.

## Experiment designer
Use the \designer to check a proposed titration before collecting data. Select the instrument, cell and syringe concentrations, injection count, volume mode, and optional small first injection. Volumes can be entered manually or calculated from syringe capacity.

Choose a model and adjust parameters to inspect the predicted titration. Enable **Simulate noise** and set **Noise level** to explore its effect. Fit the simulated data to examine whether the design may constrain the model.

# Tandem designs

Tandem mode repeats the injection series for each syringe load, with a small first injection at each segment start when enabled. Concentrations advance between segments using the tandem back-mixing model; see **Tandem experiments** for its assumptions.

## Buffer subtraction
Select a reference buffer experiment and one or more targets in the Buffer Subtraction tool, then apply the correction. Original integrated heats remain stored and raw files are unchanged.

**Matched:** subtract matching buffer injections, using nearby valid injections as fallback.

**Linear:** subtract a line fitted to the included buffer injections.

**Exp. decay:** subtract a single exponential fitted to the included buffer injections.

If the reference is missing after saving a target separately, its stored included heats retain the correction, including after target reintegration. **Missing reference (stored values retained)** identifies this case; the stored reference heats cannot be reprocessed.

# Corrected heat and uncertainty

Corrected heat is target minus reference heat. Assuming independent errors, its SD is the square root of the sum of their squared SDs.

Matched subtraction uses the reference injection SD, or combines SDs when nearby injections are averaged. Linear and Exp. decay subtraction use uncertainty in the fitted reference curve at that injection, not the full scatter of single reference heats. Too few reference points can leave scatter unestimated; a zero reference SD does not mean the correction is exact.

## Tandem experiments
Tandem experiments can be collected by refilling the syringe while leaving the current cell content, producing multiple segments that should be treated as a single continuous titration. The tandem experiment merger combines selected loaded datasets into a single merged experiment.
The standard merge concatenates thermograms and recomputes injection concentrations and ratios across the combined titration. If an input experiment has already been baseline processed, the merger uses its baseline-corrected trace for that segment.
Back-mixing mode adds a simple overflow/dead-volume model between syringe loads. You can set the dead volume, choose whether displaced titrated solution was removed between segments, and adjust the fraction of the dead volume that mixes back into the active cell. The merged experiment stores segment start concentrations so processing, fitting, and project saving treat it as one tandem dataset. Its comments retain the first source’s notes and append the merge method, auto criterion when used, settings, and selected fractions in reload order.

Select **Auto back-mixing** (**Auto** on macOS), then choose **One-site** or **Model-free** under **Auto criterion**. One-site uses a binding model; Model-free matches the two sides of each reload without specifying a binding model. Both infer corrections from the data rather than measuring liquid mixing.
Model-free estimates can be less precise with noisy data or reloads near saturation. Compare the two criteria when a one-set-of-sites model is appropriate.
Tandem concatenated experiments retain fewer adjustable experiment parameters than normal experiments due to the calculations required to do the concatenation.
When the first source experiment has an external experiment ID, the merged ID uses that value followed by `-concat`; if it is blank, the merged ID stays blank. Cell and syringe sample/batch IDs are kept only when every source has the same nonblank value. The merger does not open the import review; select the merged experiment and open **Details > Identifiers** to add or change IDs later.

# Back-mixing between reloads

At each reload, the model optionally removes titrated overflow and then mixes the selected fraction of the remaining dead volume with the active cell. For macromolecule and ligand separately, the next cell concentration is the volume-weighted average of the current cell concentration and the concentration in that mixed dead-volume fraction. The active-cell volume remains fixed; the calculation changes the next segment's concentrations, not the measured heat peaks.

The back-mixing factor is the fraction of a homogeneous dead-volume compartment that exchanges with the active cell between segments. During each segment, displaced amounts accumulate in the dead or overflow volume. The selected injection-bookkeeping method governs displacement within every segment; it is separate from the exchange between reloads. See **Injection bookkeeping** for its concentration updates and equations.

# Automatic back-mixing calculation

**One-site** chooses reload fractions by minimizing the one-set-of-sites RMSD for the combined titration.

**Model-free** estimates reloads in order, retaining earlier fractions. For each candidate fraction, it recalculates concentrations and fits one unweighted cubic to heat per mole of injectant against midpoint molar ratio. It uses included injections among the six nearest positions on each side, requiring at least three per side. Excluded injections still enter the concentration bookkeeping.

The cubic must keep rising or keep falling across the window. This assumes the local isotherm does not turn near the reload. Where the data barely distinguish fractions, a weak, chosen preference favors 5%; it is not measured mixing information.

## Traceability and attribution
Enable **Traceability Mode** to keep excluded injections visible in figures and add report attribution, interpretation source and editing history, and sign-off fields. Excluded points remain excluded from fitting.

Confirm the operator at launch. **Continue** saves the entered name; **Quit** or closing the confirmation exits. If the operator changes during a session, update the name in General Preferences before creating or updating results.

# Experiment and sample identifiers

With Traceability Mode and **Prompt for experiment and sample IDs after import** enabled, review identifiers after each raw-data import batch. Project imports do not trigger the review. IDs are optional and may repeat; filenames are not substituted for them. **Apply** saves edits; **Skip** or closing keeps the data without those edits. Use **Details > Identifiers** to edit them later.

# Result and report attribution

New and successfully updated Analysis Results record the current operator. Reports identify their preparer and generation time. In Traceability Mode, enter a **Report ID** and complete the exported signature/date fields as needed; saved analysis operators and experiment/sample IDs are included in report details.

Missing attribution appears as **Not recorded**; blank experiment/sample IDs are shown that way only in Traceability Mode. Preview updates capture the current preparer and time, and export refreshes them if the operator has changed.

# Experiment attributes

Edit experiment attributes in experiment details to supply metadata for derived analyses and multi-experiment constraints. They are saved in the project; changing an attribute used by a fit requires updating that result.
