## Baseline and Integration
The integrated heat for each injection is calculated from the baseline-corrected thermogram over the selected integration window. Baseline choice and integration range are therefore coupled: changing the selected peak region can change which points are used to estimate the baseline and can also change the integrated area directly.

# \appname supports three baseline strategies:
**Spline baseline:** local baseline estimates are placed around injection scopes and interpolated with a linear or smooth spline. Sparse, balanced, and dense point-density settings change the target number of control points per injection. The program adapts the actual point count to the usable baseline length, especially when integrated peak regions remove much of the available baseline.
**Polynomial baseline:** a single polynomial is fit across the thermogram while outlier points are iteratively rejected. This is a global description of baseline drift and is most appropriate when the baseline is smooth across the full experiment.
**Segmented baseline:** local polynomial segments are fit in the baseline regions surrounding each injection and blended across integration windows. This is useful when baseline drift changes locally and should not be forced into one global polynomial.

When the setting to discard integration regions for baseline fitting is enabled, points inside selected peak windows are excluded from the baseline fit. This reduces peak contamination in the baseline estimate, but it also means integration edits can affect subsequent baseline calculations. Locking the processor or spline points can be useful when the desired baseline should be preserved.

## Peak Error Bars
The error bar drawn on each injection point represents the program's estimate of the standard uncertainty of that injection's integrated heat, \sigma{q,i}. The value is computed as the combination of an integration-noise contribution and a baseline-level contribution:

                                \sigma{q,i} = √( \sigma{q,i,int}^2^ + \sigma{q,i,bl}^2^ )

Integration noise contribution:

                                \sigma{q,i,int} = \sigma{p,i} · ∆*t* · √*N*{int,eff}

Here, \sigma{p,i} is the baseline RMS noise level estimated from non-integrated points surrounding injection *i*, ∆*t* is the sampling interval, and *N*{int,eff} is an effective number of integrated samples. *N*{int,eff} is based on the actual number of integrated samples (*N*{int}), but adjusted to compensate for autocorrelation in the baseline noise because neighboring samples are not fully independent.

Baseline level contribution:

                                \sigma{q,i,bl} = \sigma{p,i} · (*T*{int} / √*N*{bl,eff})

Here, *T*{int} is the integration length in seconds, and *N*{bl,eff} is an effective number of baseline samples used to estimate the baseline level. As above, *N*{bl,eff} is adjusted to compensate for autocorrelation in the baseline noise.

## Parameter Uncertainties
Parameter uncertainty is estimated after the primary best fit using residual bootstrap, leave-one-out refitting, or profile likelihood. Each method measures uncertainty or sensitivity under its own assumptions.

**Residual bootstrapping:** Included primary-fit residuals are divided by their effective injection SDs, centered, and sampled with replacement. Each sampled residual is multiplied by the target injection's effective SD and added to the best-fit prediction. Refitting these synthetic datasets gives a distribution for each fitted parameter. Missing injection SDs use the same fallback rule as weighted fitting.
**Leave-One-Out Refitting:** The fit is repeated multiple times while removing one data point at a time. Each refit omits one injection for a single-experiment fit or one entire experiment for a global fit. Concentrations, uncertain model options, and parameter locks remain fixed at their primary-fit settings.

For each parameter such as *N*, \dh, or \kd, \appname collects the distribution of fitted values across those refits. For a residual-bootstrap parameter, the reported SD is the root-mean-square deviation of retained refit values from the primary best-fit value. The 95% confidence limits are the 2.5th and 97.5th percentiles of those values. These summaries are transformed or propagated into the displayed quantities.
The parameter values reported are not averages. They are the single best-fit values that minimize the loss function. Resampling estimates uncertainty without replacing the primary best-fit values.
The general uncertainty style preference controls whether formatted values are shown with standard deviations, confidence intervals, or both where the relevant interval information is available. This is a display and export-format choice; it does not change the underlying fit.
**Profile likelihood:** The profile method estimates intervals at a fixed 95% confidence level. It varies one fitted parameter at a time, holding it at each trial value while refitting the other free parameters. A single-experiment profile uses that experiment's included observations and fitted coordinates; a global profile uses the complete objective and shared coordinates. Unweighted and weighted profiles use an F-calibrated worsening relative to the best residual score. Weighted profiles retain processing-derived peak-area SDs as unchanged relative injection weights and estimate the overall residual scale separately; fitting never writes that scale back to an injection SD. A parameter bound reached before the threshold is computational censoring, not a confidence endpoint, so that side remains unavailable.
Profile results retain the primary best-fit value. Tables continue to show `value ± SD`; for a profile interval this SD is an equivalent display scale calculated from the two 95% endpoints, not a claim of Gaussian sampling uncertainty. The exact endpoints are retained for diagnostics and direct one-coordinate transformations. Advanced analyses can sample the stored values and uncertainty summaries, but profile fitting does not create a bootstrap ensemble or a joint covariance model. Save the project as `.ftxtc` to preserve profile diagnostics, including the outcome and any censoring on each side. Older projects retain their existing uncertainty behavior when opened.
## Bootstrap Parameter Correlation
The correlation matrix uses the usable residual-bootstrap refits with finite values for every displayed parameter. For each off-diagonal pair it reports Pearson's *r*, the complete-refit count *B*, and an approximate 95% Monte Carlo precision interval obtained from Fisher's transformation: *z* = atanh(*r*), *z* ± 1.959964/√(*B*−3), transformed back with tanh. Exact self-correlations on the diagonal do not have a Fisher interval.
This interval describes finite-simulation precision of the estimated correlation. It is not a confidence interval for either fitted parameter, does not replace bootstrap parameter uncertainty, and does not establish identifiability, causality, model adequacy, or model validity. An interval spanning zero leaves the sign unresolved only at the current Monte Carlo precision. Frequent failed refits can select which synthetic datasets remain in the ensemble, an effect the Fisher interval does not include. With *p* displayed coordinates, *B* complete rows structurally limit the centered covariance rank to at most *B*−1; that sample-count warning is distinct from numerical rank and scientific validity.
# Derived Quantities
Derived parameters such as \dg and \tds use the application's uncertainty-transformation and propagation rules. Their displayed limits are not necessarily the percentiles obtained by recalculating the complete derived quantity for every refit. Profile likelihood does not directly profile quantities that depend on several parameters or create a joint covariance model.
# Concentration Uncertainty Propagation
When concentration uncertainty is enabled, \appname perturbs cell and syringe concentrations in residual-bootstrap refits. Leave-one-out and profile likelihood keep concentrations fixed. Each entered fractional SD is the arithmetic standard deviation relative to its concentration. The synthetic multiplier is positive and lognormal with σ²log = ln(1 + CV²) and μlog = −σ²log/2, so it has mean 1 and SD CV; explicit cell or syringe SDs take precedence over the automatic concentration SD.

## \multexp and Analysis Results
When you analyze multiple experiments using \multexp with **Create analysis result** enabled, a combined Analysis Result is added to the data list.
Parameters in this result may be shared across experiments, fitted per experiment, or made dependent on an experimental variable such as temperature under the selected constraint scheme.
The reported global parameters are not averages. They are the single best-fit values or dependence descriptors that minimize the total mismatch across the included datasets.

Analysis Results keep the solver metadata, model options, parameter constraints, individual replicate rows, and evaluated thermodynamic quantities together. When temperature dependence is present, evaluated values are calculated at the selected evaluation temperature; otherwise they are evaluated at the mean experiment temperature. The result exporter can write either one summary row per result or all replicate rows. Summary rows aggregate parameter values across the result's replicate solutions, while all-row exports preserve the per-experiment fitted values and losses. Exported uncertainty can be formatted as standard deviation, 95% confidence interval lower and upper bounds, or both.

Advanced result tabs are shown only when the result contains the required information. Temperature-dependent structuring analysis requires a sufficient temperature span. Ionic-strength analysis requires salt metadata and a meaningful ionic-strength variation. Protonation analysis requires buffer metadata that varies across the included experiments.

## Tandem Experiments
Tandem experiments represent a titration continued after one or more syringe reloads. In a merged tandem dataset, the injections from all selected segments are treated as one continuous titration, but each segment can have its own starting active cell and titrant concentrations. When back-mixing compensation is used, the back-mixing factor is the fraction of a homogeneous dead-volume compartment that is mixed with the active cell volume between tandem experiment segments before the next segment begins.

The standard concatenation path joins the thermograms, shifts injection times, preserves injection bookkeeping, and recalculates the concentration and molar-ratio progression across the combined titration. This is appropriate when the reload can be treated as a continuation without explicit back-mixing correction.

Back-mixing mode uses an active-cell plus dead-volume model between segments. During each segment, injected titrant displaces mixed solution into the dead or overflow volume. Between segments, the model can remove displaced titrated solution before applying the selected back-mixing exchange. This changes the starting active cell and titrant concentrations for the next segment. The merged dataset stores these segment concentrations so fitting uses the tandem mass balance rather than treating every reload as a fresh experiment.

The dilution-method preference governs injection displacement in both standard concatenation and back-mixing mode. For cumulative injected volume relative to active cell volume *u*, MicroCal uses the reference curves A{M}(*u*) = (1 - *u*/2)/(1 + *u*/2) and B{M}(*u*) = *u*(1 - *u*/2); the exponential method uses A{E}(*u*) = exp(-*u*) and B{E}(*u*) = 1 - exp(-*u*). For an injection from *u*{0} to *u*{1}, r = A(*u*{1})/A(*u*{0}), M{1} = rM{0}, and L{1} = rL{0} + C{s}[B(*u*{1}) - rB(*u*{0})]. After back-mixing, M{0} and L{0} are the mixed active-cell concentrations, while cumulative *u* is not reset. Without back-mixing, the transitions reproduce the ordinary reference curves exactly.

The MicroCal curves come from Malvern Instruments, *MicroCal ITC Analysis Software Using Origin User Manual*, MAN0577-02-EN-00 (20 May 2015), section 12.3.1, equations 2 and 4. The arbitrary-state transition is an \appname extension derived from those curves, not a manufacturer-specified back-mixing equation. Stateful MicroCal advancement stops before *u* = 2 because A{M}(2) = 0: advancing from that point would divide by zero, while extending the approximation further would produce negative retained concentrations. The exponential method has no finite-volume boundary.
Automatic back-mixing estimates the mixing fraction by an adaptive grid search. The scan first samples the full 0-100% range, then refines around the best candidate and finishes with 0.2 percentage-point resolution. For experiments with one or two reload transitions, each candidate merged dataset is scored by an unweighted one-set-of-sites fit without error estimation. The mixing condition with the lowest one-set-of-sites model RMSD is used for the final merged experiment.

## Model Formalism
The analysis models in \appname are implemented in accordance with the MicroCal/Origin formal definitions. The implementation is also extended to concentration bookkeeping and dilution correction during fitting. Parameter values from \appname are therefore intended to be directly comparable to MicroCal-style analyses, although differences in baseline handling can still introduce small shifts in fitted values.
For binding affinity parameters, the optimizer fits log10(*K*) rather than *K* directly. Reported affinity values are converted back to the displayed \kd and thermodynamic quantities after fitting.

# Syringe Correction Mode
In the default MicroCal-style interpretation, the fitted N-term can absorb apparent error in the effective concentration or activity of the species in the cell. This means that N is not always a pure stoichiometric parameter unless concentrations and active fractions are known accurately.
Syringe correction mode provides an alternative parameterization in which the fitted correction factor is applied to the titrant concentration delivered from the syringe instead of being interpreted primarily on the cell side. The thermogram integration and heat values are unchanged; the difference is entirely in the mass-balance interpretation used during fitting.
When this mode is enabled, the fitted parameter is reported as α{syringe}. Results obtained with and without syringe correction mode should therefore not be interpreted as strictly equivalent parameterizations of the same fit.
