# Desktop fit statistics and diagnostic-only reduced chi-square

## Decision

Reduced chi-square measures residual scatter against the integration SDs saved with the fit. Those SDs estimate uncertainty from thermogram processing. Even when the relative weights are useful, the absolute scale can differ from experimental repeatability in either direction. Use RMSD and the residual plot to assess the size and pattern of the mismatch. Use AICc and ΔAICc to compare models fitted to the same observations under the same likelihood assumptions.

Remove reduced chi-square from routine desktop displays, Standard analysis reports, and Standard result-table exports. Retain it when the user selects **Diagnostic report** or **Diagnostic export**. Keep the calculation and saved evidence. The independent collection currently computes the sum of standardized residual scores divided by the sum of residual degrees of freedom. The routine pooled display goes away with this change.

## Results workspace in native macOS and Avalonia

- In **Summary**, move **Solver** immediately below **Validity**. Keep **RMSD** and **Molar RMSD** adjacent in **Result** whenever both are available. Preserve the Summary assessment and **Modify Assessment** control, information criteria, and the relative order of the other sections.
- In **Analysis**, replace the **Null hypothesis test** section with stacked **Binding** and **Null** groups, in that order. Each group shows **RMSD**, then **AICc**. Show **ΔAICc** directly below the Null group, followed by the existing **Conclusion** with its effective outcome and manual or automatic mode. Omit the Null model type row from this inspector. Keep the existing graph and Null prediction controls.
- For a single experiment, show its primary fit and saved Null comparison. For a joint fit, show the whole binding fit and its result-level Null comparison, even when an experiment is selected. For an independently fitted collection, use the selected experiment's binding fit, member Null comparison, and member assessment. Show the experiment name above the groups. Without a valid selection in the current result, show a prompt to select an experiment.
- Use saved evidence at the displayed scope. Binding RMSD comes from the primary fit convergence and Null RMSD from the saved Null comparison. Format both as unweighted heat RMSD using the shared formatter and the desktop's selected energy unit family. For binding AICc, use the binding criteria from the matching saved comparison when present, otherwise use the saved member or result criteria at that scope. For Null AICc, use the saved comparison's Null criteria. Show **Unavailable** with the applicable saved reason when a value is missing. Each RMSD remains visible when its AICc is unavailable. The AICc rows show AICc only. Use the saved signed ΔAICc and existing comparison eligibility and reason, with **Null AICc − binding AICc** in its tooltip.
- Define the rows, formatting, tooltips, and scope selection once in Core. Render them using each desktop's existing controls and selection refresh paths. Keep the current stale-result indicators and assessment policy.
- Remove reduced chi-square from all routine desktop placements, including Summary, the experiment table, result detail windows, and the live fit inspector. Remove presentation options and label-sizing workarounds that served only those placements. The live fit inspector keeps its other existing rows and layout.
